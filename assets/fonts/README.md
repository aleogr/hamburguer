# Fontes

- **Anton** — títulos. SIL Open Font License 1.1.
- **Inter** — texto corrido. SIL Open Font License 1.1.

As duas licenças permitem hospedar os arquivos no próprio servidor, que é o que
este projeto faz: nenhuma requisição sai para o Google. Os arquivos aqui contêm
apenas os subsets `latin` e `latin-ext` (o bastante para português).

Texto integral das licenças:
<https://fonts.google.com/specimen/Anton/license> e
<https://fonts.google.com/specimen/Inter/license>.

Para baixar de novo (ou atualizar de versão), rode `bash tools/fetch-fonts.sh`.
